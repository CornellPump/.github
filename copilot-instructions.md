# Copilot PR Review Instructions

Apply the style guide for each file type present in the PR diff.
Do NOT apply rules from one language's guide to another.

- Python (`.py`) → see `copilot-style-guides/python.md`
- TypeScript (`.ts`, `.tsx`) → see `copilot-style-guides/typescript.md`
- JavaScript (`.js`) → see `copilot-style-guides/javascript.md`
- SQL (`.sql`) → see `copilot-style-guides/sql.md`
